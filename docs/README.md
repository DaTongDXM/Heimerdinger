## 一句话定位

**不是选股工具，是纪律执行工具。** 把「位置优先 → 信号确认 → 类型化出入场规则 → 观察池跟踪」固化为每日流水线，解决 8 笔实盘复盘暴露的核心问题：**入场有清单、出场零清单**。

## 三条不可违背的原则

1. **先位置、后信号** —— 信号在错误位置上无效。下跌中继必须硬过滤出局。
2. **出场计划前置** —— 没有完整「入场单 8 项」就不允许开仓；入场后规则锁定，盘中不可改。
3. **20 笔样本前不调参** —— 只记录，不调优。回测引擎是调参的唯一合法入口。

## 六阶段流水线

```
① 数据层(universe + 日线 qfq)
   → ② 位置分类（硬过滤，下跌中继出局）
   → ③ 信号筛选（只对非下跌中继计算）
   → ④ 类型匹配与候选池
   → ⑤ 入场单生成（人工填 8 项，系统强制校验）
   → ⑥ 持仓监控/出场触发 + 观察池管理
```

- 运行时点：每日收盘后（15:30 后）跑 ①→④；次日开盘只做触发确认。
- 唯一人工环节：⑤ 的目标价/止损价定价。

## 命名隔离声明

本文档中的 **A / B / C = 交易类型**（短线动量 / 波段跟随 / 左侧分批建仓），
与项目 `timo`（提莫）中的 **S/A/B/C = 信号档位**不是同一概念。
Heimerdinger 是**全新独立系统**，不复用 timo 的代码与配置。
