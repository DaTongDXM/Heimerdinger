# 短线交易系统（timoo）产品需求文档

| 字段 | 内容 |
|------|------|
| 产品名称 | timoo（暂定，内部代号） |
| 项目路径 | `D:\wxd\code\timoo` |
| 产品定位 | 个人短线交易纪律执行系统——把「位置优先 + 信号确认 + 类型化出入场规则」固化为每日流水线，用系统纪律替代盘中主观判断 |
| 规范来源 | 《个人短线交易系统框架规范 v1.3》（2026-09-18） |

> 本文档不涉及 `timo` 的任何既有逻辑。

## 1. 背景：这份 PRD 要解决的到底是什么问题

v1.3 规范由 2026-07-29 至 2026-09-18 的 **8 笔实盘复盘**归纳而来。复盘暴露的问题不是"选不出票"，而是**交易纪律在执行环节系统性失效**。三条核心实证：

| # | 实证结论 | 数据 |
|---|---------|------|
| 1 | **位置对收益的区分度 > 信号本身** | 底部/多头组均值 +7.0%（4/4 胜） vs 下跌中继组 +0.4%（含唯一亏损） |
| 2 | **入场有清单、出场零清单** | 7 笔短线入场均走同一信号族，但卖出全部是盘中即兴；没有一笔在买入当天写好目标价/减仓位/保护线 |
| 3 | **无跟踪机制导致两种错误同时存在** | 科士达 9/4 卖 37.02，9/14 收复 37.1，今日 39.31（错过 +6.2%）；双环 8/11 离场后 -8.9%（管了反而亏） |

**一句话问题定义**：不是缺少选股信号，而是缺少一个**在开仓前强制生成完整出场计划、并在持仓期间按锁定规则执行**的系统。

## 2. 产品目标

### 2.1 三个正交目标

| 目标 | 衡量方式 |
|------|---------|
| **G1 位置优先** | 任何标的必须先过位置分类，下跌中继 100% 不进入候选池；顺序不可颠倒（先位置、后信号） |
| **G2 出场计划前置** | 100% 的开仓动作在系统中存在完整「入场单 8 项」快照，缺一项不允许标记"已开仓" |
| **G3 闭环可验证** | 每笔出场自动回填（实际价/持有天数/出场类型/命中规则），月度可统计分类型胜率与违规次数 |

### 2.2 非目标（Non-goals，明确不做）

1. **不做券商对接 / 自动下单** —— 系统是决策支持，不是交易执行。
2. **不做盘中指标计算** —— 指标一律用 T-1 及以前的收盘数据；盘中只做"触发确认"。
3. **不做资金流驱动的择时** —— 主力净额永久禁用为入场/出场触发器（9/14-15 双反例）。
4. **不做荐股 / 不输出"买点必中"结论** —— 输出的是候选池与纪律约束，不是收益承诺。
5. **MVP 不做回测引擎** —— 参数调优的前置条件是回测，回测放 Later（见 ROADMAP）。
6. **不覆盖科创板、北交所、ST 股** —— 见 P0-1。
7. **不替代人工判断定价** —— 六阶段中只有"目标价/止损价定价"保留人工（由系统强制留空位给人填）。

## 3. 用户故事

1. **As a 个人投资者**，I want 每天收盘后跑一次全流程拿到「按位置+信号过滤后的候选清单」，so that 我从几十只候选里挑标的，而不是翻遍 5000 只股票。
2. **As a 容易即兴交易的人**，I want 系统在标记"已开仓"前强制我填完入场单 8 项（含写死的止损价、第一目标价、时间止损），so that 不再出现"买入当天既没有目标价也没有保护线"。
3. **As a 持仓者**，I want 系统每天按**入场时锁定**的出场规则给出明确动作，so that 盘中不再临时改规则、不再用"主力流出了""感觉超买了"即兴卖出。
4. **As a 事后复盘者**，I want 出场后自动回填实际出场价、持有天数、命中哪条规则，so that 月度能统计分类型胜率、盈亏比和违规次数。
5. **As a 怕踏空的人**，I want 盈利平仓后 30 分钟内系统阻止我开新仓，so that 杜绝"胜利后遗症"式的 5 分钟连开仓。
6. **As a 被止损出局的人**，I want 出场标的自动进观察池并预写再入场触发条件，so that 不再凭感觉决定要不要买回来。

## 4. 核心概念（术语表，避免歧义）

| 术语 | 定义 | 取值 |
|------|------|------|
| **位置（Position）** | 价格结构分类，硬过滤层 | 底部反转 / 多头回踩 / 下跌中继 / V型 |
| **信号（Signal）** | KDJ、MACD、量能的组合状态 | 标准组合 / 强信号 / 无 |
| **类型（Type）** | 交易类型，决定持有周期与出场规则 | A 短线动量 / B 波段跟随 / C 左侧分批建仓 |
| **入场单（EntryOrder）** | 开仓前必须写全的 8 项计划，快照不可修改 | 见 STRATEGY_SPEC §5 |
| **观察池（WatchPool）** | 出场后强制进入的跟踪队列，预写再入场触发 | 活跃 / 已触发 / 已清除 |
| **T（交易日）** | 运行当日；**所有指标基于 T-1 及以前收盘计算** | — |

**关键顺序约束**：位置 → 信号 → 类型。**信号在错误位置上无效**（阳光电源实证：金叉出现在 MA60 下方 24% 的下跌中继，最终 -1.7%）。

### P0 - Must Have（MVP 必须交付）

## 6. 关键流程（六阶段流水线）

```
① 数据层(universe+日线)
   → ② 位置分类(硬过滤，下跌中继直接出局)
   → ③ 信号筛选(只对非下跌中继计算)
   → ④ 类型匹配与候选池
   → ⑤ 入场单生成(人工填写 8 项，系统强制校验)
   → ⑥ 持仓监控/出场触发 + 观察池管理
```

- **运行时点**：每日收盘后（15:30 后）跑 ①②③④；次日开盘只做触发确认。
- **唯一人工环节**：⑤ 的目标价/止损价定价。其余全部程序化。
- **顺序不可颠倒**：先位置、后信号。

## 7. UI 结构（Web UI，P1）

```
┌──────────────────────────────────────────────────────┐
│  timoo   [候选池] [入场单] [持仓] [观察池] [复盘]      │
├──────────────────────────────────────────────────────┤
│  顶部状态条：数据日期(T-1) | 候选 N 只 | 持仓 M 笔 | 违规 0 次 │
├──────────────────────────────────────────────────────┤
│                    页面内容区                          │
└──────────────────────────────────────────────────────┘
```

**候选池页**（P1-6）
```
┌─ 摘要 ─────────────────────────────────────────┐
│ 扫描日期 2026-09-18 | universe 3210 | 候选 23   │
│ A类 8 | B类 5 | C类 10 | V型标记 2（仓位减半）   │
└────────────────────────────────────────────────┘
┌─ A 类 · 短线动量（持有1-3日，单层）─────────────┐
│ 代码  名称  位置    信号明细      建议关注位  操作 │
│ 300207 欣旺达 底部反转 KDJ低位金叉+绿柱缩短+V1 17.02 [填入场单]│
└────────────────────────────────────────────────┘
```

**入场单页**（P1-7）：8 项表单，0-7 编号对应规范；第 7 项自检触发时按钮置灰并给出原因（"距上次盈利平仓仅 12 分钟"）。

**持仓页**（P1-8）：每行显示「类型 / 锁定止损价 / 第一目标价 / 时间止损剩余 / 今日是否触发」，触发行高亮并给出"次日动作"。

**观察池页**（P1-9）：显示再入场触发条件与剩余观察天数（20 日倒计时）。
