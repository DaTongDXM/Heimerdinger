# 策略规则工程化规格（Strategy Spec）

> 来源：《个人短线交易系统框架规范 v1.3》 | 版本：v1.0 | 日期：2026-09-18

> 术语约定：`T` = 运行当日；所有指标基于 **T-1 及以前的收盘数据**；`C(t)` = 第 t 日收盘价。

## 1. 阶段① 数据层

### U-1 板块过滤

```
保留（代码前缀）：
  600 / 601 / 603 / 605   # 沪市主板
  000 / 001 / 002 / 003   # 深市主板（含原中小板）
  300 / 301               # 创业板
剔除：
  688 / 689               # 科创板
  43xx / 83xx / 87xx / 92xx 及 8 开头其余   # 北交所
```

**U-2 ST 动态重判**：每次运行按**最新股票名称**重判，名称含 `ST` / `*ST` / `退` 即剔除。
禁止使用缓存名单——股票随时可能戴帽/摘帽。

**U-3 次新股剔除**：上市不足 130 个交易日直接剔除（MA60 与 120 日高点无法计算）。

**U-4 实现要点**：`ak.stock_zh_a_spot_em()` 一次取全量列表（代码 + 名称）→ 按前缀与名称过滤 → 输出 universe（约 3200 只）→ 再逐只拉历史。

### D-1 字段与复权

| 字段 | 用途 |
|------|------|
| `date` | 时序对齐 |
| `open` | ⚠️ **规范 §1.2 未列出，但 §4.2 A 类出场"跌破当日开盘价"需要**，实现时必须取 |
| `high` / `low` | 平台振幅、止损保护、KDJ |
| `close` | 均线、平台、位置判定 |
| `vol` | 底量、放量判定 |

- 复权：**统一前复权 `adjust="qfq"`**（除权除息日不复权会产生假跳空，污染平台与跌幅计算）。
- AKShare qfq 是**滚动复权**（以最新价为基准），历史值随除权变动 → 平台/底量判定只关心**相对值**（振幅、量比）；绝对价仅用于当次运行，**禁止跨日缓存复权价做比较**。

### D-2 清洗规则

| 情况 | 处理 |
|------|------|
| 停牌日缺失 | 按自然交易日对齐；`close=NaN` → 前向填充；`vol` 填 0（参与底量判定但不触发放量） |
| 主源单只失败 | 重试 2 次 → 切腾讯源（symbol 需 `sh`/`sz` 前缀：6 开头→sh，0/3 开头→sz）→ 仍失败记入失败清单，**不阻塞全流程** |
| 限速 | 逐只 `time.sleep(0.3~0.5)` |

### D-3 缓存与拉取深度

- 落地：SQLite 或 parquet，按日增量。
- 有缓存：只拉最近 5 日 + 当日；无缓存/缺数据：全量拉 **180 个交易日**（规范 130 为下限，留余量）。
- 首次建库约 30-50 分钟；此后每日增量 5-10 分钟。

### D-4 口径强制规则

1. 所有指标基于**已收盘日线**，不做盘中动态值。
2. 盘中现价只用于入场单的**触发确认**（如"现价站上前日收盘"），不参与指标计算。
3. 禁止用盘中动态均线否定收盘静态均线（9/9 均线口径实证：两者都对，差异仅源于是否纳入今日）。

## 2. 阶段② 位置三分类（硬过滤）

> **输出唯一值**：`position ∈ {底部反转, 多头回踩, 下跌中继, V型}`
> **判定顺序**：先判下跌中继（X1/X2）→ 命中即出局；再判底部反转（P1-P4 全满足）；再判多头回踩（M1+M2）；最后判 V 型例外。

### 2.1 底部反转（可入 → A/C 类标的池）

P1-P4 **全部满足**才算：

| ID | 表达式 | 参数 |
|----|--------|------|
| **P1** | `(max_close_120 − max_close_60) / max_close_120 ≥ D1` | `D1 = 0.15` |
| **P2** | 平台内 `(max_close − min_close) / min_close ≤ D2`，平台长度 `N ≥ D3` | `D2 = 0.08`、`D3 = 10` |
| **P3** | 平台内存在单日 `vol ≤ 平台期日均 vol × D4` | `D4 = 0.6` |
| **P4** | `abs(MA60(t) − MA60(t−1))` 连续 `D5` 日递减 | `D5 = 5` |

✅ **Q1 已确认（2026-09-18）**：采用**自适应扩展**——以 T-1 为终点向前延伸，振幅 ≤ `D2` 则继续，上限 40 日，取最长满足的平台。
⚠️ 落地前必须用 8 笔实证标的反验（TC-9），确认分类结果与复盘结论一致后再定稿。

```python
def detect_platform(closes, T, d2=0.08, min_len=10, max_len=40):
    """以 T-1 为终点向前扩展，振幅 ≤ d2 时继续延伸，取最长平台。"""
    end = T - 1                      # 平台终点
    best = None
    for n in range(min_len, max_len + 1):
        start = end - n + 1
        if start < 0:
            break
        seg = closes[start:end + 1]
        amp = (seg.max() - seg.min()) / seg.min()
        if amp <= d2:
            best = (start, end, n, amp)   # 记录最长满足的平台
        else:
            break
    return best
```

⚠️ **表述歧义（Q2）**：P1 文字"更早高点（120日内最高收盘价前段）"与公式不一致，**以公式为准**。

### 2.2 多头回踩（可入 → A/B 类标的池）

| ID | 表达式 |
|----|--------|
| **M1** | `MA20(T−1) > MA20(T−6)` 且 `close(T−1) > MA20 > MA60`（多头排列） |
| **M2** | 最近 3 个交易日内，最低价触及 `MA20 × [0.98, 1.02]`，且期间**每日收盘均 > MA20** |

### 2.3 下跌中继（禁入）

| ID | 表达式 |
|----|--------|
| **X1** | `close(T−1) < MA60(T−1)` 且 `(MA60 − close)/MA60 ≥ X1`，**同时不满足 P2 平台条件** |
| **X2** | 或：虽有平台但平台长度 `< D3`（10 个交易日） |

→ 命中即从候选池剔除，**不进入信号筛选**。`X1 = 0.10`。

### 2.4 V 型反转（例外）

| ID | 表达式 | 参数 |
|----|--------|------|
| **V-1** | 满足 X1 价格位置，但 5 日内涨幅 `≥ 12%` | 硬编码 0.12 |
| **V-2** | 且放量：`vol ≥ V4 × 基准量` | ⚠️ **V4 规范未定义，建议 1.8**（复用底量后放量倍数） |

处理：允许入候选池，但**仓位强制减半**，标记 `V型`。

## 3. 阶段③ 信号族（与位置结果做 AND）

### S-1 KDJ（9, 3, 3）

```
RSV = (C − LLV(L,9)) / (HHV(H,9) − LLV(L,9)) × 100
K   = 2/3 × K_prev + 1/3 × RSV
D   = 2/3 × D_prev + 1/3 × K
J   = 3K − 2D
金叉：K(t−1) ≤ D(t−1) 且 K(t) > D(t)，且发生在 D < 50 区域（低位金叉才有效）
```

边界：`HHV − LLV = 0`（一字板/停牌）时 RSV 取 50。初值 `K_prev = D_prev = 50`。

### S-2 MACD（12, 26, 9）

```
DIF  = EMA(C,12) − EMA(C,26)
DEA  = EMA(DIF,9)
hist = DIF − DEA
绿柱缩短：hist(t) < 0 且 |hist| 连续 ≥ 2 日递减
金叉：hist 上穿 0
超买警告：J > 100 或 K > 85（仅提示，不作出场触发器）
```

### S-3 量能（三选一，按类型定）

| ID | 表达式 | 参数 |
|----|--------|------|
| **V1** | `vol(t) ≥ 平台底量日 vol × V1` | `V1 = 1.8` |
| **V2** | 连续 3 日 `vol ∈ [MA5(vol)×1.2, MA5(vol)×2.5]` | — |
| **V3** | `vol(t−1) < MA5(vol)×0.8` 且 `vol(t) > MA5(vol)×1.3` | — |

### S-4 信号有效组合（阶段④入口）

| 组合 | 结论 |
|------|------|
| KDJ 低位金叉 + MACD 绿柱缩短 + 量能任一 | ✅ 标准 A 类入场信号 |
| MACD 金叉 + KDJ 金叉 + 放量 | ✅ 强信号（欣旺达 9/9 型） |
| 仅 KDJ 金叉 | ❌ **无效**，禁止单独触发买入（9/15 实证：下跌中 KDJ 反复金叉死叉，金叉当日即失效） |
| 仅主力资金流 | ❌ **永久禁用**，同步描述指标，不作入场或出场触发器（9/14-15 双反例） |

⚠️ **代码约束**：**禁止实现"即将金叉""即将转正"分支**——那是预测不是观察。只认"当日已发生"。

## 4. 阶段④ 类型匹配

| 类型 | 持有周期 | 位置来源 | 入场信号 | 仓位规则 |
|------|---------|---------|---------|---------|
| **A 短线动量** | 1-3 日 | 底部反转 或 多头回踩 | S-4 标准组合 | 单层 |
| **B 波段跟随** | 5-20 日 | 多头回踩（必须） | MACD 金叉 + 回踩确认 | 1-2 层，回踩加仓 |
| **C 左侧分批建仓** | 20-60 日 | 底部反转平台内 | **不等信号**，平台 + 底量即分批 | 2 层起，每跌 X% 加 1 层 |

✅ **Q4 已确认（2026-09-18）**：采用**方案 B · 按失效价空间等分**。

```
P0        = 首层建仓价
S         = 失效价 = 平台下沿 × 0.98
space     = (P0 − S) / P0          # 建仓价到失效价的总空间
step      = space / 3              # 等分 3 段
加仓触发   = 价格每下跌一个 step 加 1 层，共可加 2 层（D7 封顶 4 层）
```

与平台结构自动适配：无论平台振幅是 3.6% 还是 8%，加仓点位始终落在"建仓价 → 失效价"之间，
且**最大亏损敞口可在入场时一次算清**——左侧越跌越买，必须先知道最坏情况。

**示例**：`P0 = 50.00`，平台下沿 `48.50` → `S = 48.50 × 0.98 = 47.53`
→ `space = (50.00 − 47.53)/50.00 = 4.94%`，`step = 1.65%`
→ 跌至 **49.18** 加第 3 层、跌至 **48.35** 加第 4 层（封顶）、跌破 **47.53** 全部离场。

**实现约束**：加仓点位必须在入场单第 4/5 项生成时一并算出并写入快照，事后不得口头调整。
⚠️ `B 类"回踩加仓"` 触发条件未定义（Q5），建议：回踩 MA20 不破且收盘站回 MA5 → 加第 2 层。

```python
# 匹配规则（伪代码）
底部反转 + 信号         → A 类候选
多头回踩 + 信号         → A / B 类候选
底部反转 + 平台底量(无信号) → C 类候选
V型 + 信号              → A 类候选（标记减半）
```

## 5. 阶段⑤ 入场单 8 项（缺一项不开仓）

| # | 字段 | 取值来源 / 校验 |
|---|------|----------------|
| 0 | `trade_type` | `A` / `B` / `C`，锁定后**不可更改**（决定出场规则） |
| 1 | `structure_position` | `底部反转` / `多头回踩` / `V型减半` + 附 P1-P4 或 M1-M2 判定数据快照 |
| 2 | `observed_facts` | KDJ 状态、MACD 柱、量能、与 MA60 距离 —— **只写观察，禁写预测**（系统校验：禁止出现"即将""应该""预计"字样） |
| 3 | `stop_loss_price` | **写死的数字**。A = 前日收盘价；C = 平台下沿 × 0.98 |
| 4 | `first_target_price` | 结构位（前高 / 平台上沿）+ 到位减半规则 |
| 5 | `remainder_protection` | A = 跌破当日开盘价；B = 2 日收盘破 MA5 |
| 6 | `time_stop` | A = 3 日 / B = 20 日 / C = 20 日 |
| 7 | `self_check` | ① 是否盈利后 30 分钟内开仓？② 是否上一笔刚平？**任一为是 → 不开** |

✅ **Q8 已确认（2026-09-18）**：以**入场当日的前一日收盘价**为准，填入场单第 3 项后随快照锁定，此后不可修改。
（理由：止损价必须唯一确定，不能随持有天数漂移成"移动靶"。）

**保存约束**：
- 0-7 全部非空才允许 `status = OPEN`。
- 保存后为 **append-only 快照**，任何字段不可修改（发现错误只能作废重建，并留痕）。

## 6. 阶段⑥ 出场规则（入场时锁定，盘中禁止换规则）

| 类型 | 止损 | 目标 | 时间止损 |
|------|------|------|---------|
| **A** | 收盘跌破**前日收盘价** → 次日开盘清仓 | 第一目标 = 最近结构位（前高/平台上沿），到位**减半**，剩余以跌破当日开盘价保护 | 3 个交易日信号未兑现 → 无条件离场 |
| **B** | 连续 **2 日收盘**价 < MA5 → 离场（双环 8/11 实证，八笔最佳出场）。**禁止用盘中价触发** | 移动止盈：从最高收盘回撤 `B1` 离场 | 20 个交易日 |
| **C** | **固定失效价** = 平台下沿 × 0.98（写死的数字，入场时填入） | 平台突破后转 B 类规则管理 | 20 个交易日无进展（未突破平台上沿）→ 离场 |

**C 类特别条款**：KDJ 超买、单日破 5 日线、盘中破分时均线——**永久禁止作为 C 类出场触发器**。
（云南白药实证：震荡平台里这些指标天天报警，50.35 卖在区间下沿。）

**出场判定运行时点**：收盘后统一判定，输出"次日动作"，不在盘中触发。

## 7. 观察池与再入场（W-*）

```
出场当天 → 强制入观察池 + 按出场类型预写再入场触发：
  错杀/止损型（A 类触发、C 类失效价）：
      触发 = 收盘价收复出场日最高价
          或 位置分类重新"可入" + 信号族复现
  趋势确认型（B 类 2 日破 MA5）：
      休眠，直到重新满足 P1-P4 / M1-M2 才唤醒
入池 20 个交易日无触发 → 自动清除
```

实证依据：科士达 9/4 卖 37.02 → 9/14 收复 37.1 → 今日 39.31（错过 +6.2%）；双环 8/11 离场后 -8.9%（不管不亏）。无跟踪机制时两者事前无法区分。
