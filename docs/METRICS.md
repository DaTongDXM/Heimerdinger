# 验证闭环与指标体系（Metrics）

> 版本：v1.0 | 日期：2026-09-18 | 对齐规范 §9「记录与验证闭环」

---

## 1. 为什么北极星指标不是收益率

8 笔样本的收益里，市场 β、运气、纪律三者无法分离；用收益率做北极星会导致**凭单笔盈亏改参数**——这正是规范明令禁止的行为。

北极星指标必须满足：**可控、可归因、与长期收益单调正相关**。

> ### 🌟 北极星指标：计划执行率（Plan Adherence Rate, PAR）
>
> **PAR = 完整执行「入场单 8 项 + 按锁定规则出场」的交易笔数 / 总交易笔数**
>
> | 项 | 值 |
> |----|----|
> | 基线（2026-07-29 ~ 09-18，8 笔） | **0%** —— 7 笔短线入场有信号清单，但**无一笔**在买入当天写好目标价/减仓位/保护线 |
> | MVP 上线 1 个月目标 | **≥ 80%** |
> | 3 个月目标 | **≥ 95%** |
> | 归因 | 完全由用户是否使用系统决定，不受行情影响 |

收益类指标降级为**驱动指标**，且只在样本 ≥20 笔后才允许用于决策。

## 2. 三层指标体系

```
        北极星：计划执行率 PAR
                  ▲
        ┌─────────┼─────────┐
   驱动指标                驱动指标
  (纪律质量)              (策略质量)
        │                     │
  入场单完整率          分类型胜率/盈亏比
  出场规则命中率        位置分类命中率
  位置事前判定率        观察池再入场收益
        │
   健康指标（系统可信度）
  数据完整率 / 扫描耗时 / 违规次数
```

### 2.1 驱动指标 · 纪律质量

| 指标 | 定义 | 基线 | 目标 |
|------|------|------|------|
| **入场单完整率** | 8 项全填的笔数 / 总笔数 | 0%（实证） | 100% |
| **出场规则命中率** | 由锁定规则触发的出场 / 总出场 | 0%（卖出全为即兴） | ≥90% |
| **位置事前判定率** | 开仓前系统已给出 position 的笔数 / 总笔数 | 0%（分类只在事后做） | 100% |
| **冷却违规次数** | 盈利平仓后 30 分钟内开新仓次数 | 1 次（9/15 阳光电源，间隔 5 分钟） | 0 |
| **即兴卖出占比** | 出场原因为"主力流出/超买/怕回吐"等未在规则中的占比 | 高（7 笔中多数） | ≤10% |

### 2.2 驱动指标 · 策略质量（样本 ≥20 笔前仅记录）

| 指标 | 定义 | 实证基线（8 笔） |
|------|------|-----------------|
| **分类型胜率** | A/B/C 各自盈利笔数 / 笔数 | 待积累 |
| **分类型盈亏比** | 平均盈利额 / 平均亏损额 | 待积累 |
| **位置分类命中率** | 底部/多头组平均收益 − 下跌中继组平均收益 | **+7.0% vs +0.4%（差值 6.6pt）** ← 框架立足点 |
| **观察池再入场收益** | 触发再入场后的平均收益 vs 未跟踪的主观回买 | 科士达错过 +6.2%；双环 -8.9% |
| **时间止损有效性** | A 类 3 日未兑现即离场的平均亏损 vs 硬扛 | 待积累 |

> ⚠️ **位置分类命中率是本框架的唯一立足点**。
> 若样本扩大后该差值消失（底部组不再显著优于下跌中继组），则整个"位置优先"假设失效，需要回到规范层重做——不是调参数能解决的。

### 2.3 健康指标 · 系统可信度

| 指标 | 定义 | 阈值 |
|------|------|------|
| **数据完整率** | 成功拉取日线的股票数 / universe 数 | ≥99% |
| **日线缺失率** | 停牌/缺数据填充占比 | ≤1% |
| **扫描耗时** | 全流程耗时 | 增量 ≤10 分钟 |
| **失败股票数** | 主备源均失败的数量 | 记录，>50 只告警 |
| **违规次数** | N1-N8 各条命中次数 | N1/N2/N4-N8 = 0 |
| **无入场单交易数** | 系统中存在持仓但无对应入场单 | **0**（发现即阻断） |

## 3. 记录与回填规范

### 3.1 入场时（快照，append-only）

保存 `entry_order` 8 项完整快照 + 生成时刻的指标值（KDJ/MACD/量能/与 MA60 距离）。
**任何字段不可修改**；发现错误只能作废重建并留痕。

### 3.2 出场时（自动回填）

| 字段 | 来源 |
|------|------|
| `exit_date` / `exit_price` | 人工确认或次日开盘价 |
| `hold_days` | 系统计算 |
| `exit_type` | 止损 / 目标达成减半 / 剩余保护 / 时间止损 / 移动止盈 / 人工干预 |
| `hit_rule` | 命中的具体规则 ID（如 `E-A-1`、`E-B-2`） |
| `is_planned` | **是否为锁定规则触发** —— PAR 的计算依据 |

## 4. 参数调优门禁（硬约束）

```
样本 < 20 笔  →  参数只记录，禁止调优（规范 §9）
样本 ≥ 20 笔  →  必须先有回测引擎（P2-1），回测样本 ≥20 笔，方可改参数
改参数        →  生成新的 param_version（含生效日期与理由），旧版本结果可复现
```

**任何"凭单笔盈亏改参数"的行为，一律拒绝执行。** 连续亏损时正确的动作是增加样本、检查纪律执行率，而不是调 D2/D3。

## 6. 指标定义纪律

1. 每个指标必须有：**定义公式、基线值、目标值、数据来源表**。
2. 禁止用"感觉良好""胜率还行"这类不可计算表述进入统计。
3. 区分**观察到的事实**与**推断出的结论**——统计表只放事实，结论单列并标注置信度。
4. 样本量必须随每个统计结果一同展示（`n=8` 与 `n=50` 的结论权重不同）。
